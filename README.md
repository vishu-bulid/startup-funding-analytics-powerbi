# 🚀 Startup Funding Analytics | Power BI

An interactive **Power BI dashboard** designed to analyze startup funding trends across industries, cities, investors, startups, and investment types.

## 📊 Dashboard Preview


## 🎯 Project Overview

This project analyzes startup funding data to identify key investment trends and provide business-focused insights through an interactive Power BI dashboard.

The dashboard helps explore:

- 💰 Total startup funding
- 🏢 Funding by industry vertical
- 🌍 Funding by city
- 📅 Funding trends over time
- 💼 Investment type distribution
- 🚀 Top-funded startups
- 👥 Investor activity

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
- **Data Cleaning**
- **Data Visualization**

## 🧹 Data Preparation

The dataset was prepared using Power Query, including:

- Date format standardization
- Handling missing values
- Cleaning inconsistent text values
- Removing unwanted characters
- Handling errors in funding amounts
- Data type conversion
- Text cleaning using Trim and Clean

## 📈 Key Dashboard Metrics

| KPI | Description |
|---|---|
| 💰 Total Funding | Total funding raised by startups |
| 🚀 Total Startups | Number of unique startups |
| 👥 Unique Investors | Number of unique investors |
| 📊 Average Funding | Average funding amount per startup |

## 🔍 Dashboard Features

- Interactive slicers
- Industry-wise funding analysis
- City-wise funding analysis
- Year-wise funding trends
- Top 5 investment types
- Top-funded startups
- KPI cards
- Interactive Power BI visuals
